## 2. Description of Service

GitPulse is an educational platform for supporting DevOps education and evaluating teamwork in GitLab projects. The Service provides:

- Automated synchronization and analysis of data from GitLab repositories
- Dashboard with activity and teamwork metrics
- Automated assessment based on configurable rules (R01-R13)
- Email notifications about progress and assessments
- Data export in CSV and JSON formats
